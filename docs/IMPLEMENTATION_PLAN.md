# 实施计划和边界

依据用户上传的 1.0 需求书，首次增量落实 M0/M1，不宣称完成整个 Alpha 验收。

1. M0：Python 包、PySide6 导航、配置路径、日志、SQLite / SQLAlchemy / Alembic。
2. M1：建筑 CRUD 中的新建、编辑、检索、归档；独立营建阶段；拖拽/多选/文件夹入库；哈希去重；原件与归属分离；元数据、基本预览、重启持久化。
3. 下一增量 M2：插件解析器、后台任务状态、PDF 页码 / XLSX 单元格 / DXF 实体证据定位。原件保持不可变。
4. M3：AI Provider 与发送范围授权、原始提取、审核版本及争议，严格区分知识状态。
5. M4–M5：审核知识检索、纠错召回、摘要与比较，不跨建筑套用知识。

本轮数据库只建立有业务支撑的四张表；其余需求实体随 M2–M5 增量迁移，不用空表假装功能完成。
