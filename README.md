# ECTA-GS · Alpha 0.1.1

面向中国早期木构建筑研究的离线桌面工作台。本次增量将“解析与人工审核”占位页替换为可用的本地工作区；AI 服务尚未接入，不向外部发送资料。

## Windows 安装和更新

安装 Python 3.12 或 3.11（64 位）。下载仓库 ZIP，**全部解压到独立文件夹**，双击 `start-windows.cmd`。首次启动自动创建虚拟环境、下载依赖；已有虚拟环境会检查软件版本和解析依赖，必要时更新安装。此版本仍为源码版，无独立 exe。

从 0.1.0 更新：关闭旧软件，备份数据目录后，将新版 ZIP 解压到新文件夹并运行新启动脚本。无需搬移原件，默认用户数据目录不变。启动时先备份旧数据库，再运行 Alembic 0002 迁移，保留所有建筑档案和资料。若过去设置了 `ECTA_GS_DATA_DIR`，请继续使用相同路径；不要同时运行新旧版本。升级后不要用旧代码打开已升级数据库。

手动安装/更新（在项目目录打开 PowerShell）：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e "."
.\.venv\Scripts\python.exe -m ecta_gs
```

只有 Python 3.11 时将 `-3.12` 改为 `-3.11`。无需激活虚拟环境或修改 PowerShell 执行策略。下载依赖需要联网，软件正常使用不需要网络或 AI 密钥。Linux/macOS 可使用 `python3 -m venv .venv` 和 `.venv/bin/python` 执行相同命令。

## 资料入库

1. 在“建筑档案”中新建建筑，记录已知字段、年代依据和营建阶段；未知字段可留空。
2. 在“资料投喂”顶部选择本批建筑归属，填写来源说明；未知归属默认进入未分配资料箱。
3. 拖入文件/文件夹，或使用选择按钮。文件夹递归导入，跳过符号链接和软件自身数据目录。
4. 原件复制时计算 SHA-256，完成后才提交记录；同建筑重复内容不重复建档，不同建筑可关联相同原件。
5. 选中资料查看哈希、状态、预览，保存建筑归属、来源和备注。

有审核条目的资料不允许直接改到另一栋建筑名下，以保持知识与证据的建筑归属一致。若相同资料涉及多栋建筑，可从原输入文件另行导入目标建筑，共享只读原件、分别整理知识。已有相同原件关联时拒绝静默合并备注。

## 使用解析与人工审核

1. 打开“解析与审核”，选择建筑筛选和文件。点击“解析所选 / 重新解析”，或批量解析当前筛选下的未解析、失败、中断资料。
2. 等待后台解析完成。左栏显示原件信息和所选证据的原文摘录；PDF 显示对应页，图片显示全幅。中栏显示本次运行的解析器版本、提示、证据定位和内容。
3. 从运行下拉框可查看以前的解析结果；重新解析不会删除以前的结果或审核知识。
4. 选中一个证据片段，点击“选中片段 → 加入待审核”。文件必须已经归属某栋建筑。
5. 在右栏修改内容，选择类型以及 `measured`（实测/直接记载）、`derived`（推导）、`analogy`（类比）、`hypothesis`（假设）。新建条目默认待审核、假设，不自动标成实测。
6. 填写修改者和理由，点击“保存待审核”“确认”“否决”或“争议”。**修改只有点击按钮后才保存，切换条目或刷新前请先保存。** 推导请写公式、输入、方法；类比请写对象、适用条件和依据。
7. 下方查看每次修改前后值、理由、署名及时间。已确认条目仍可修订，所有历史版本保留；重复使用过期编辑版本会被拒绝，不静默覆盖。

本轮的“解析结果”是确定性文本/结构提取，**不是 AI 语义提取**。从原文整理知识的动作由用户执行。署名由用户填写，不是多用户身份认证。置信度不会替代证据，也不会自动确认知识。

## 解析格式和证据定位

| 格式 | 本轮能力与边界 |
| --- | --- |
| PDF | 按页提取文本和可识别表格；保留页码、表编号和表格区域；无文本页标记待 OCR。表格可能漏识别，需核对原页。 |
| DOCX | 段落、段落样式、顶层表格单元格；不编造页码。页眉页脚、文本框、嵌套表尚未提取。 |
| XLSX | 所有工作表中非空单元格、坐标、公式及缓存值；不执行公式，缺失缓存明确标记，缓存可能过期。 |
| CSV | 尝试识别编码和分隔符；保存记录序号与实际文本行范围，多行单元格不伪装成单行；首行只标记为候选表头。 |
| TXT / MD | 文本及行号；保留编码信息，自动估计编码时需核对。 |
| JSON | 语法校验、结构化展示；定位精度明确为文件级根节点，不表示符合建筑领域 schema。 |
| DXF | 布局顶层图层、文字、几何/尺寸实体属性、句柄；块内实体未展开，几何量不自动当作建筑实测尺寸或物理单位。 |
| JPG / PNG / TIFF 等 | 人工预览、文件级证据；标记待 OCR，不虚报已识别文字。 |
| DOC / XLS / DWG 等 | 保留原件，明确尚不支持解析；提示转换为 DOCX / XLSX / DXF。 |

单次文件解析上限 100 MiB，DOCX/XLSX 总解压体积上限 256 MiB，单工作表范围上限 20 万单元格，单次结果上限 2 万片段或 500 万字符。超限时整次解析失败，不提交截断结果；原件保留。大文件请拆分后重新导入。

任务按批次串行后台运行，当前批次结束后才能关闭或开始另一批。强制退出的任务在下次启动时标记中断，可以重试。失败详情和历次运行可查，旧结果、知识不会被新失败覆盖。

## 数据目录、备份和恢复

默认使用 `platformdirs` 的用户数据目录，Windows 通常为 `%LOCALAPPDATA%\ECTA-GS`，以设置页显示的路径为准：

- `database/ecta.sqlite3`：建筑、文件关联、解析任务/片段、知识、审核和版本历史。
- `library/objects/<哈希前两位>/<完整哈希>`：原件，数据库保留原始文件名与扩展名。
- `extracted/task-<任务号>.json`：每次运行的独立解析产物；重新解析不覆盖旧运行。
- `backups/`：升级前及手动创建的数据库快照。
- `logs/ecta.log`：轮转运行日志；无外部 AI 调用或 API 密钥存储。

可以在启动前指定数据目录：

```powershell
$env:ECTA_GS_DATA_DIR = 'D:\ECTA-GS-Data'
.\.venv\Scripts\python.exe -m ecta_gs
```

**完整备份**：等待任务结束并关闭软件，复制整个数据目录到独立位置。设置页“备份数据库快照”不包含原件，不能替代完整备份。

**完整恢复**：关闭软件，先保留当前目录副本，将完整备份复制到新的空目录，设置 `ECTA_GS_DATA_DIR` 指向该目录，再用兼容版本启动。不要覆盖或删除现有资料库。数据库迁移升级前自动备份，不提供自动删除表的降级。

只支持单进程使用同一资料库；不要在多台设备上同时写同步目录。磁盘或进程故障可能留下临时片段、无数据库关联的完整原件/解析产物，不自动清理原件。建议本地 NTFS，入库的原子硬链接发布依赖文件系统支持；不支持会报错。独立备份仍然必要。

## 当前未实现

云端/本地 AI Provider、AI 语义提取、OCR 引擎、自动资料冲突检测、跨资料比较、构件领域专表和知识库专页、研究助手、向量检索、三维和 CAD 生成。当前争议由人工标记，不自动推断不同尺寸必然冲突。来源备注编辑尚无版本历史，知识审核有独立完整历史。列表尚未分页，海量片段可能使界面刷新变慢。
